# Client – ΕΡΓΑΣΙΑ ΙΙ (Angular)

## Περιγραφή
Ο φάκελος `client/` περιέχει το frontend της Εργασίας ΙΙ.

Υλοποιείται με Angular (standalone components + router) και επικοινωνεί με το backend μέσω REST API.

## Προϋποθέσεις
- Node.js / npm
- Ο backend server να τρέχει στο `http://localhost:4000`

## Εγκατάσταση
Από τον φάκελο `client/`:

    npm install
## Εκτέλεση
Από τον φάκελο `client/`:
    npm start
Η εφαρμογή τρέχει στο: `http://localhost:4200`
